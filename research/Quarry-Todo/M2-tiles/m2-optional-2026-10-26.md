## FR-TILE-08 done 2026-10-27

- `tile.palette_set(tiles, weights?, random_rotate?, tileset?)` stores a weighted palette in the view (not undoable, like the brush); an empty list clears it. While it is set, `tile.place` and `tile.fill_rect` pick one tile per cell by weight, optionally turned a random quarter. The pick is a seeded hash, so replaying the same commands gives the same floor.
- Tileset panel, "Random palette" section from the design: tiles with their share, an add cell that takes the brush's tile, click to weigh a tile more (1 to 9), right-click to remove, Rotation Off or Random 90° steps.
- Test `a_palette_scatters_tiles_by_weight`: 2 tiles at 1:1 over 100 single placements land 35 to 65 each; a tile past the end of the sheet is refused.
- `QUARRY_UI` `run=` now takes JSON args (`run=tile.place {"cells":[[0,0]]}`), used for the screenshot.
