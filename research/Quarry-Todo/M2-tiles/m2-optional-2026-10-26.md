## FR-TILE-08 done 2026-10-27

- `tile.palette_set(tiles, weights?, random_rotate?, tileset?)` stores a weighted palette in the view (not undoable, like the brush); an empty list clears it. While it is set, `tile.place` and `tile.fill_rect` pick one tile per cell by weight, optionally turned a random quarter. The pick is a seeded hash, so replaying the same commands gives the same floor.
- Tileset panel, "Random palette" section from the design: tiles with their share, an add cell that takes the brush's tile, click to weigh a tile more (1 to 9), right-click to remove, Rotation Off or Random 90° steps.
- Test `a_palette_scatters_tiles_by_weight`: 2 tiles at 1:1 over 100 single placements land 35 to 65 each; a tile past the end of the sheet is refused.
- `QUARRY_UI` `run=` now takes JSON args (`run=tile.place {"cells":[[0,0]]}`), used for the screenshot.

## The rest, 2026-10-27

- FR-TILE-07 block brush: `tile.block(cells?, remove?, object?)` puts a 1 m cube of brush tiles (or palette picks) on each cell: 6 faces on 8 shared corners. Walls between neighbouring blocks cancel like voxels, and removing a block gives its neighbour the wall back; removing where no block stands changes nothing. The Block tool in Tiles now uses it (right-click removes).
- FR-TILE-06 sticky placement: `tile.attach(face, edge, object?)` stands a brush tile on an edge of a tile face, square to it, 1 m along its normal, wound so a wall on a floor edge faces the floor. With Sticky placement ticked, a Place click within 0.3 m of a tile's edge attaches there instead of placing on the plane.
- FR-ART-05: Settings has Choose and Use default for the image editor (an .app on macOS); Windows and Linux now run the chosen editor too (directly, file as its only argument, never a shell). Linked textures get an "Open in image editor" button in the Paint panel; tilesets already had one.
- Tests: one block is 6 faces on 8 corners, two are 10 on 12, removing one restores the other's wall; a floor edge wall is square to the floor and faces it.
- For review: the Block tool, sticky clicks and the editor picker by hand.
