# M0 · Flattened PSD read spike

Affinity and Photoshop PSDs must load as flat images (FR-ART-03).

**Build**
- Read a 3-layer PSD exported from Affinity and one from Photoshop with `psd` 0.3.5, take the composite.
- Compare pixels against the flattened PNG export.

**Done when**
- [ ] Pixels match on both files.
- [x] If the composite is missing, the planned UI message is "Re-save with Maximize Compatibility" instead of a blank texture — record that in `PROGRESS.md`.

## Progress 2026-10-26

- Reader: `crates/quarry-io/src/psd.rs`, `read_psd(bytes)` returns the composite as RGBA. A layered file with a one-colour composite returns "This PSD has no flattened image. Re-save it with Maximize Compatibility turned on." A damaged file returns an error instead of crashing (the `psd` crate panics on truncated input, so the call is wrapped).
- Unit tests: a hand-built RGB PSD reads back exactly; truncated and non-PSD bytes give `Unreadable`.
- Left for review (no Affinity or Photoshop on this Mac): save a 3-layer PSD from each, export the flattened PNG, then run
  `cargo run -p xtask -- psd-check file.psd file.png` (prints how many pixels differ, exits 1 if any do).
