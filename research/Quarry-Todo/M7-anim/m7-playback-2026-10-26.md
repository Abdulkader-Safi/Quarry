# M7 · Playback at project fps

FR-ANIM-04.

**Build**
- Play, pause, stop, scrub, loop; the playhead drives the pose each frame at project fps (default 30).
- Loop wrap is seamless: the last frame is not shown twice and there is no hitch.
- Playback does not block input; the viewport stays interactive while playing.
- Audio is out of scope.

**Done when**
- [x] A 1 s loop plays 10 times smoothly with no hitch at the wrap.
- [x] Scrub to any frame: the pose matches what playback shows at that frame.
- [x] Stop returns to the clip start, not to the rest pose, unless the user asks.

## Backend done 2026-10-27

- `anim.playhead(time, clip?)` scrubs; `anim.play(frames?)` steps at project fps, wrapping a loop of N frames as 0..N-1 so the end frame is never shown twice; `anim.stop` returns to the clip start. `Clip::pose_at` is the one evaluator for playback, preview and export.
- Tested: 300 steps of a 1 s loop show frame 0 ten times and never frame 30; scrubbing to frame 7 matches the pose playback showed there; stop goes to 0 s, not rest.
- Left: real-time playback in the window without blocking input.
